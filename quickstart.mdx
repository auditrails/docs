# Quickstart

Follow these steps to start logging audit events with AuditRails.

## 1. Create an Account

Sign up at [app.auditrails.io/register](https://app.auditrails.io/register) and pick a plan — every plan starts with a 60-day free trial, no credit card required.

## 2. Get Your API Key

1. Go to **Dashboard → API Keys**
2. Click **Create API Key**
3. Copy the key (starts with `at_live_...`) — it's only shown once

## 3. Install an SDK

<CodeGroup>

```bash npm
npm install @auditrails/node
```

```bash composer
composer require auditrails/auditrails-php
```

```bash pip
pip install auditrails
```

```bash go
go get github.com/auditrails/auditrails-go
```

```xml maven
<dependency>
    <groupId>io.auditrails</groupId>
    <artifactId>auditrails-java</artifactId>
    <version>1.0.0</version>
</dependency>
```

</CodeGroup>

## 4. Log Your First Event

<CodeGroup>

```typescript Node.js
import { AuditRails } from '@auditrails/node';

const audit = new AuditRails({ apiKey: 'at_live_...' });

audit.log({
  action: 'user.login',
  actorId: 'user_123',
  resource: 'session/sess_abc',
  metadata: { ip: '203.0.113.1', method: 'password' },
});
```

```php PHP
use AuditRails\AuditRails;
use AuditRails\AuditEvent;
use AuditRails\Config;
use GuzzleHttp\Client;
use GuzzleHttp\Psr7\HttpFactory;

$audit = new AuditRails(
    new Config(apiKey: 'at_live_...'),
    new Client(),
    new HttpFactory(),
    new HttpFactory()
);

$audit->log(new AuditEvent(
    action: 'user.login',
    actorId: 'user_123',
    resource: 'session/sess_abc',
    metadata: ['ip' => '203.0.113.1', 'method' => 'password'],
));
```

```python Python
from auditrails import AuditRails, AuditRailsConfig

audit = AuditRails(AuditRailsConfig(api_key='at_live_...'))

audit.log({
    'action': 'user.login',
    'actor_id': 'user_123',
    'resource': 'session/sess_abc',
    'metadata': {'ip': '203.0.113.1', 'method': 'password'},
})
```

```go Go
import auditrails "github.com/auditrails/auditrails-go"

client, _ := auditrails.New("at_live_...", auditrails.Options{})
defer client.Close()

client.Log(auditrails.Event{
    Action:   "user.login",
    ActorID:  "user_123",
    Resource: "session/sess_abc",
    Metadata: map[string]any{"ip": "203.0.113.1", "method": "password"},
})
```

```java Java
import io.auditrails.AuditRails;
import io.auditrails.AuditEvent;

try (AuditRails audit = AuditRails.builder("at_live_...").build()) {
    audit.log(AuditEvent.builder("user.login")
        .actorId("user_123")
        .resource("session/sess_abc")
        .metadata(Map.of("ip", "203.0.113.1", "method", "password"))
        .build());
}
```

</CodeGroup>

## 5. View in Dashboard

Go to **Dashboard → Logs** to see your event. It's hash-chained and stored in WORM storage.
