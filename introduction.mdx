# Welcome to AuditRails

AuditRails is a **tamper-proof audit logging platform** that helps you achieve compliance (SOC 2, HIPAA, ISO 27001, GDPR, PCI DSS) with minimal engineering effort.

## What AuditRails Does

  <Card title="Immutable Logs" icon="lock">

  </Card>
  <Card title="Compliance Ready" icon="shield-check">

## How It Works

```
Your App → SDK → AuditRails API → Hash Chain → WORM Storage + Search
```

1. **Install an SDK** in your application (5 languages supported)
2. **Log events** with `audit.log({ action, actorId, resource, metadata })`
3. **Events are hash-chained** using SHA-256 — each log links to the previous one
4. **Stored immutably** in S3 with Object Lock (WORM) and searchable in ClickHouse
5. **Query and verify** through the dashboard or Read API

## Key Features

| Feature | Description |
|---------|-------------|
| **Hash Chaining** | SHA-256 per-tenant chains — any tampering breaks the chain |
| **WORM Storage** | S3 Object Lock in COMPLIANCE mode — logs cannot be deleted or modified |
| **Real-time Search** | ClickHouse-powered search across billions of events |
| **Multi-tenancy** | Every API key maps to a tenant. Complete data isolation. |
| **RBAC** | Admin, Member, and Auditor roles with appropriate access |
| **CSV Export** | Export filtered logs for external audit review |
| **Compliance Dashboard** | Track your posture across all 18 active compliance frameworks |
